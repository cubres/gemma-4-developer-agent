Reviewed 11 October 2026. These observations describe inspected source and retained local evidence; they do not establish a newly accepted native run.

1. In the inspected `native_arm.py`, the timing receipt sets `infrastructure_error` from whether an exception escaped the outer `evaluate` call. The pinned organiser `swegemma/evaluate.py` can instead catch a task exception and return an ordinary `TaskResult` with an error and a negative test exit. It also returns error-bearing results for missing snapshot or failed agent paths. A false outer flag therefore does not prove task health.
2. `PrivateJUnitReceipts.summary()` requires at least one final invocation and checks the evidence for those it saw. It does not itself require one final invocation for every task in `PROTOCOL.task_ids`. The arm and supervisor check row count, not a task-to-final-event denominator. An error-bearing task plus other successfully captured tasks is a source-level route to a misleadingly positive aggregate. The invented controls exercise this ambiguity; no such new native outcome was observed here.
